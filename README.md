# One Line, Big Laugh

A tiny Node 22 TypeScript entry for the One Line, Big Laugh bounty. Running `main.ts` writes one original funny line — a wedding-vows request that ends in a proposal from the AI itself — to `/output/entry.txt`. One line, no setup, no explanation, just the joke landing on its own.
